Private by design · self-hosted

A little help,
right in WhatsApp.

Inkling is an open-source personal assistant operated privately for its owner and a few friends. Each installation can choose its own assistant name.

Talk naturally to get help finding information, keeping lists, setting reminders and managing everyday tasks. Optional integrations add email, calendars, browser tasks and coding projects.

Mail, with your permission

The mail integration connects a Google account that you choose. It can search and read Gmail, prepare drafts and send email after you approve the exact preview in a later message.

Connecting Google is optional. Gmail tools are available only in the connected person's private chat, never in group chats. Google account access can be disconnected at any time.

Your own assistant

This website describes the open-source software and its private mail integration. It does not host the assistant, collect email or provide public sign-up. The operator of each installation controls its server, access list and optional providers.

Read the Privacy Policy and Terms of Service before connecting an account. For questions or deletion requests, contact the operator through your existing private WhatsApp chat with the assistant.
